يفحص مساحة القرص، ويعيد المحاولة تلقائيًا بمسار أكثر ثباتًا إذا فشل التسريع أو نفدت الذاكرة — بنفس الدقة وFPS.

التثبيت

ثلاث خطوات، مرة واحدة فقط.

  1. ثبّت Python 3.11 أو أحدث من python.org أو من متجر مايكروسوفت.
  2. ثبّت FFmpeg وأضفه إلى PATH البرنامج يعتمد عليه كليًا: winget install Gyan.FFmpeg ثم أعد تشغيل الجهاز.
  3. فك الضغط ثم شغّل Setup.bat مرة واحدة بعدها افتح VideoCraftStudio.exe في أي وقت.
تنبيه: ويندوز قد يعرض تحذير SmartScreen لأن الملف غير موقّع رقميًا. اضغط «مزيد من المعلومات» ← «تشغيل على أي حال».
