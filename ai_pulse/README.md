# نبض AI

أخبار ومقاطع الذكاء الاصطناعي في مكان واحد. قسم منفصل داخل موقع VideoCraft، على المسار `/ai/`.

## كيف يشتغل

```
زائر يفتح /ai/
  → الصفحة تطلب /ai/feed.json
  → السيرفر يرجّع آخر نسخة فوراً
  → إذا عمرها أكثر من ساعة: يحدّثها في الخلفية (ingest.py)
       يسحب من المصادر ← يحذف المكرر ← Claude يكتب منشور عربي + تصنيف (إذا فيه مفتاح)
  → الصفحة تعيد الفحص كل 10 دقائق
```

التحديث يصير داخل السيرفر ويُحفظ في مجلد مؤقت، فما يحتاج commit (أي push على `main` يعيد نشر Render).
`web/feed.json` نسخة أولية تظهر أول ما يصحى السيرفر، لين يخلص أول تحديث.

## المصادر

| المصدر | النوع |
|---|---|
| OpenAI، Google DeepMind، Hugging Face (RSS) | أخبار |
| Hacker News (فوق 80 نقطة، آخر يومين) | أخبار |
| arXiv (cs.AI، cs.CL، cs.LG) | أبحاث |
| قنوات YouTube (`YOUTUBE_CHANNELS` في `ingest.py`) | مقاطع (تضمين من YouTube، بدون إعادة رفع) |

تضيف مصدر RSS أو قناة بسطر واحد في `ingest.py`.

## الإعداد على Render

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `ANTHROPIC_API_KEY` | (فارغ) | يفعّل التلخيص العربي. بدونه تظهر العناوين الأصلية |
| `AI_PULSE_MODEL` | `claude-opus-5-5` | موديل التلخيص (مثلاً `claude-haiku-5-5` أرخص) |

`MAX_SUMMARIES` في `ingest.py` يحدد عدد الأخبار الملخصة في كل تحديث (للتحكم بالتكلفة).

## تحديث النسخة الأولية يدوياً

```bash
python -m ai_pulse.ingest
```
